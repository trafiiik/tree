# Tree to Bash

## English

This repository contains a program that converts a tree structure  
(as defined in the EPITA TP specifications) into a Bash command  
capable of recreating the same directory and file hierarchy.

The goal of this project is to produce a litle shortcut and to stop 
bothering ourself with creating/checking the "tag archi"

---

## Français

Ce dépôt contient un programme qui convertit une structure d’arbre  
(telle que définie dans les spécifications des TP EPITA) en une commande Bash  
capable de recréer la même hiérarchie de fichiers et de dossiers.

L’objectif de ce projet est de créer un petit raccourci et d'arreter 
de s'embeter avec avec la création/le check de nos "tags archi".
